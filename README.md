# Tessera recipes

Patches and ideas for playing with [Tessera](https://github.com/Rastapopolix/tessera) on the M-Vave FM-1.

**https://default-fluid.github.io/tessera-recipes/**

New to the controls? Start with the [beginner guide](BEGINNER-GUIDE.md). Every recipe names its sounds, gives exact
button paths and values, and includes an arrangement that runs by itself after one press of **PLAY**.
